## What I'm Building

**[MnemonicAI](https://mnemonic.nishantvanawala6118.workers.dev)** — Persistent memory engine for LLM agents  
Agents capture execution events → reflection engine extracts lessons → semantic retrieval injects context before the next run. 43% cost reduction. Gets smarter while it sleeps.

**Agent Guard** — Policy engine and firewall for AI agents  
Runtime guardrails that enforce access policies, rate limits, and behavioral constraints on autonomous agents before they do damage.

**Trading Agents** — Multi-agent system with 6 distinct trading personalities  
Six agents, six risk profiles, one portfolio. From conservative value to aggressive momentum — each with its own memory, strategy, and learning loop.

**SafeLynk** — Anonymous vehicle contact system  
Let strangers reach a parked car's owner without exposing personal details. Privacy-first, no app required.
